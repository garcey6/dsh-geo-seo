sample-plugin

sample-plugin is a DeepSeek Harness plugin that adds a deterministic word counter to the composer. It answers how long a note is without sending anything to a server.

Install it with pnpm add dsh-sample-plugin, then configure maxChars and includeCjk. The plugin exposes the count_words tool and the sample.count command, and it rejects inputs above maxChars instead of truncating them.
